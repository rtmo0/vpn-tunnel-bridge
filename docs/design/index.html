Tunnel Bridge UI

Screen-by-screen design of the macOS menu bar VPN client: the menu, the Manage Tunnels window, adding a tunnel, signing in, alerts and Settings.

Menu barManage Tunnels windowAdding a tunnelSigning inAlerts and Settings

Menu bar

The menu is for connecting; everything else lives in windows. Status comes first, urgent actions next, then tunnels.

Manage Tunnels window

Sidebar with live status, details on the right. Settings save immediately; a banner asks to reconnect when a change needs it.

Adding a tunnel

Pick the kind of VPN, then a step that fits it: a file, links, or a server.

Signing in

One dialog template for every login. Connect stays disabled while a required field is empty.

Alerts and Settings

Destructive actions use a red button, errors offer the fix, background events become notifications.
