Bridge 0.10.2 makes copy and paste work in all text fields, makes long DNS and network lists readable, and fixes VPN DNS that could be lost when two tunnels are connected.

**Download `Bridge-0.10.2.dmg`** below. `Bridge.zip` is for the built-in updater of earlier versions.

## Install

Bridge is free and not notarized by Apple, so macOS warns the first time. The disk image has an installer script that copies Bridge into Applications and removes the quarantine flag:

1. Open `Bridge-0.10.2.dmg`.
2. In Terminal, run:
   ```bash
   bash "/Volumes/Bridge 0.10.2/Install Bridge.command"
   ```
3. Click the **VPN** icon in the menu bar → **Install Network Helper…** (one password prompt).

Updating: use **Update to Bridge 0.10.2…** in the menu, then **update the helper** when asked: the DNS fix is in the helper.

## What's new

- **Copy and paste.** ⌘C, ⌘V, ⌘X, ⌘A and ⌘Z now work in every text field (DNS servers, domains, networks, names, logins).
- **Readable lists.** In a tunnel's settings, **Servers**, **Only for domains** and **Networks** show the label above a full-width field that wraps, instead of one truncated right-aligned line. Repeated entries are removed when saved.
- **DNS with two tunnels.** A split tunnel whose server sends DNS but no domains (its DNS is then used for all names) could lose that DNS when a full tunnel was connected at the same time and reconnected. Bridge now moves it to the new primary network within a second, and no longer leaves a disconnected tunnel's DNS behind.

## Bridge 0.10.2 — по-русски

**Скачайте `Bridge-0.10.2.dmg`** ниже (`Bridge.zip` нужен встроенному обновлению старых версий).

**Установка.** Откройте DMG и выполните в Терминале:

```bash
bash "/Volumes/Bridge 0.10.2/Install Bridge.command"
```

Затем значок **VPN** в строке меню → **Установить сетевой помощник…**. При обновлении обновите помощник, когда Bridge предложит: исправление DNS находится в нём.

**Что нового:**
- **Копирование и вставка.** ⌘C, ⌘V, ⌘X, ⌘A и ⌘Z работают во всех полях ввода.
- **Читаемые списки.** В настройках туннеля поля «Серверы», «Только для доменов» и «Сети» теперь показывают подпись сверху, а под ней поле во всю ширину с переносом строк. Повторы убираются при сохранении.
- **DNS при двух туннелях.** Если сервер туннеля присылает DNS без доменов (тогда DNS туннеля используется для всех имён), этот DNS мог пропасть, когда одновременно подключён туннель для всего трафика и тот переподключался. Теперь Bridge за секунду переносит DNS на новую основную сеть и не оставляет DNS отключённого туннеля в системе.
