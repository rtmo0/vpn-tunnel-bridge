Bridge 0.11.3 fixes the app's memory use growing by hundreds of megabytes over a few days.

**Download `Bridge-0.11.3.dmg`** below. `Bridge.zip` is for the built-in updater of earlier versions.

## Install

Bridge is free and not notarized by Apple, so macOS warns the first time. The disk image has an installer script that copies Bridge into Applications and removes the quarantine flag:

1. Open `Bridge-0.11.3.dmg`.
2. In Terminal, run:
   ```bash
   bash "/Volumes/Bridge 0.11.3/Install Bridge.command"
   ```
3. Click the **VPN** icon in the menu bar → **Install Network Helper…** (one password prompt).

Updating: use **Update to Bridge 0.11.3…** in the menu. The helper is unchanged.

## What's fixed

- **Memory leak.** After the Tunnels or Settings window had been opened once, the app kept the closed window in memory and updated it every 2 seconds, and each update left a little memory behind: about 600 MB after three days. Closed windows are now released, and the app only updates its windows and menu when something in them actually changed.

## Bridge 0.11.3 — по-русски

**Скачайте `Bridge-0.11.3.dmg`** ниже (`Bridge.zip` нужен встроенному обновлению старых версий).

**Установка.** Откройте DMG и выполните в Терминале:

```bash
bash "/Volumes/Bridge 0.11.3/Install Bridge.command"
```

Затем значок **VPN** в строке меню → **Установить сетевой помощник…**. При обновлении через меню помощник обновлять не нужно: он не изменился.

**Исправлено:**
- **Утечка памяти.** Если окно туннелей или настроек открывали хотя бы раз, приложение держало закрытое окно в памяти и обновляло его каждые 2 секунды, и каждое обновление оставляло немного памяти: за три дня набегало около 600 МБ. Теперь закрытые окна освобождаются, а окна и меню обновляются только когда в них что-то действительно изменилось.
