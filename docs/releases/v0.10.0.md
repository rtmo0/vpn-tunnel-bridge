Bridge 0.10.0 runs the VPN backends without administrator rights, can ask for your password before tunnel changes, and adds a local proxy mode that needs no helper at all.

**Download `Bridge-0.10.0.dmg`** below. `Bridge.zip` is for the built-in updater of earlier versions.

## Install

Bridge is free and not notarized by Apple, so macOS warns the first time. The disk image has an installer script that copies Bridge into Applications and removes the quarantine flag:

1. Open `Bridge-0.10.0.dmg`.
2. In Terminal, run:
   ```bash
   bash "/Volumes/Bridge 0.10.0/Install Bridge.command"
   ```
3. Click the **VPN** icon in the menu bar → **Install Network Helper…** (one password prompt).

Updating: use **Update to Bridge 0.10.0…** in the menu, then **update the helper** when asked. This version needs the new helper: it creates the `_bridge` account the backends run as.

## What's new

**Backends without root**
- OpenVPN, OpenConnect, amneziawg-go and Xray, which parse what remote servers send, now run as the unprivileged `_bridge` account. A bug in one of them no longer hands out root.
- The helper keeps root only for tunnel interfaces, routes, firewall and DNS. It creates the utun and passes it to amneziawg-go and Xray; OpenVPN and OpenConnect open it and then drop their privileges.
- OpenVPN: Bridge now adds its routes and DNS itself (from the route-up hook and the server's PUSH_REPLY, honouring `pull-filter`). If the server pushes different settings on a reconnect, Bridge starts OpenVPN again automatically.
- Xray gets its configuration through a pipe: the user ID is no longer written to disk.
- Hook events from a backend are accepted only for its own tunnel, checked by the sending process.

**Stricter OpenVPN configs**
- Options pass through an allowlist of client options instead of a blocklist; anything else is dropped with a note in the tunnel's status.
- `<connection>` blocks are checked too, and `http-proxy` / `socks-proxy` with a credentials file are refused (OpenVPN would have read that file as root).

**Ask for my password before tunnel changes**
- New in **Settings → General → Security**. With it on, other programs running as you cannot connect, disconnect or change tunnels without a macOS password prompt. macOS remembers the password for 5 minutes.

**Local proxy mode** (VLESS, Trojan, Hysteria 2)
- In a tunnel's settings, **Connect as → Local proxy**: Bridge runs Xray as you, with no helper and no administrator rights, as a SOCKS5 and HTTP proxy on `127.0.0.1:10808` (port configurable). Only apps set to use that proxy go through it. Routing profiles work in this mode.

**Known limitation**
- OpenVPN with a one-time code (static challenge): if the server pushes different settings on a reconnect, the tunnel disconnects instead of restarting, because the code cannot be used twice. Connect it again.

## Bridge 0.10.0 — по-русски

VPN-бэкенды больше не работают от root, появился запрос пароля перед изменением туннелей и режим локального прокси без помощника.

**Скачайте `Bridge-0.10.0.dmg`** ниже (`Bridge.zip` нужен встроенному обновлению старых версий).

**Установка.** Откройте DMG и выполните в Терминале:

```bash
bash "/Volumes/Bridge 0.10.0/Install Bridge.command"
```

Затем значок **VPN** в строке меню → **Установить сетевой помощник…**. При обновлении обязательно обновите помощник, когда Bridge предложит: он создаёт учётную запись `_bridge`, от которой работают бэкенды.

**Главное:**
- OpenVPN, OpenConnect, amneziawg-go и Xray работают от непривилегированной учётной записи `_bridge`. Уязвимость в них больше не даёт root. Под root остались только интерфейсы, маршруты, файрвол и DNS.
- OpenVPN: маршруты и DNS теперь ставит Bridge (с учётом `pull-filter`). Если сервер при переподключении выдаёт другие параметры, Bridge сам перезапускает OpenVPN.
- Опции OpenVPN проходят через белый список; блоки `<connection>` тоже проверяются; `http-proxy` / `socks-proxy` с файлом учётных данных отклоняются.
- **Настройки → Основные → Безопасность → «Спрашивать мой пароль перед изменением туннелей»**: другие программы не смогут без вашего пароля подключать, отключать или менять туннели.
- **Локальный прокси** для VLESS, Trojan и Hysteria 2: в настройках туннеля «Подключать как → Локальный прокси». Xray запускается от вашего пользователя без помощника и прав администратора, SOCKS5 и HTTP на `127.0.0.1:10808`.
- Ограничение: OpenVPN с одноразовым кодом при смене параметров сервером отключится вместо перезапуска — подключите заново.
