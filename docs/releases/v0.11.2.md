Bridge 0.11.2 fixes name lookups breaking when a second tunnel's routes cover the DNS server of a tunnel that takes all traffic.

**Download `Bridge-0.11.2.dmg`** below. `Bridge.zip` is for the built-in updater of earlier versions.

## Install

Bridge is free and not notarized by Apple, so macOS warns the first time. The disk image has an installer script that copies Bridge into Applications and removes the quarantine flag:

1. Open `Bridge-0.11.2.dmg`.
2. In Terminal, run:
   ```bash
   bash "/Volumes/Bridge 0.11.2/Install Bridge.command"
   ```
3. Click the **VPN** icon in the menu bar → **Install Network Helper…** (one password prompt).

Updating: use **Update to Bridge 0.11.2…** in the menu, then **update the helper** when asked: the fix is in the helper.

## What's fixed

- **DNS of a full tunnel stays in that tunnel.** With a tunnel that takes all traffic and uses a private DNS server (e.g. AmneziaWG with `DNS = 10.17.0.1`), connecting a corporate VPN that routes `10.0.0.0/8` sent that DNS server into the corporate VPN, and every name lookup timed out. Bridge now keeps such a DNS server in its own tunnel with a host route, set whenever tunnels connect, routes change or the network changes.

## Bridge 0.11.2 — по-русски

**Скачайте `Bridge-0.11.2.dmg`** ниже (`Bridge.zip` нужен встроенному обновлению старых версий).

**Установка.** Откройте DMG и выполните в Терминале:

```bash
bash "/Volumes/Bridge 0.11.2/Install Bridge.command"
```

Затем значок **VPN** в строке меню → **Установить сетевой помощник…**. При обновлении обновите помощник, когда Bridge предложит: исправление находится в нём.

**Исправлено:**
- **DNS туннеля на весь трафик остаётся в этом туннеле.** Если туннель на весь трафик использует DNS из частной сети (например, AmneziaWG с `DNS = 10.17.0.1`), то после подключения корпоративного VPN с маршрутом `10.0.0.0/8` запросы к этому DNS уходили в корпоративный VPN, и переставали резолвиться все имена. Теперь Bridge закрепляет такой DNS-сервер маршрутом в его собственный туннель — при подключении туннелей, изменении маршрутов и смене сети.
