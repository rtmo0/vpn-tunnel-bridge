Bridge 0.10.1 fixes the app icon in the update dialog and keeps the update download in your Downloads folder until the update is done.

**Download `Bridge-0.10.1.dmg`** below. `Bridge.zip` is for the built-in updater of earlier versions.

## Install

Bridge is free and not notarized by Apple, so macOS warns the first time. The disk image has an installer script that copies Bridge into Applications and removes the quarantine flag:

1. Open `Bridge-0.10.1.dmg`.
2. In Terminal, run:
   ```bash
   bash "/Volumes/Bridge 0.10.1/Install Bridge.command"
   ```
3. Click the **VPN** icon in the menu bar → **Install Network Helper…** (one password prompt).

Updating: use **Update to Bridge 0.10.1…** in the menu, then update the helper if asked.

## What's new

- **Updates go through Downloads.** The updater downloads and unpacks the new version in `~/Downloads/Bridge-update-<version>`, then deletes that folder once Bridge has restarted. If an update fails or is interrupted, the folder is removed too. macOS may ask once whether Bridge can access your Downloads folder.
- **The right icon in dialogs.** The "update available" dialog and other alerts could show the generic white app icon after an update. Bridge now loads its icon from the app itself, and the updater re-registers the new app with macOS so the Dock and Finder show the new icon too.

## Bridge 0.10.1 — по-русски

**Скачайте `Bridge-0.10.1.dmg`** ниже (`Bridge.zip` нужен встроенному обновлению старых версий).

**Установка.** Откройте DMG и выполните в Терминале:

```bash
bash "/Volumes/Bridge 0.10.1/Install Bridge.command"
```

Затем значок **VPN** в строке меню → **Установить сетевой помощник…**.

**Что нового:**
- Обновление скачивается и распаковывается в `~/Downloads/Bridge-update-<версия>`, а после перезапуска Bridge эта папка удаляется. Если обновление не удалось или прервалось, папка тоже удаляется. macOS может один раз спросить, можно ли Bridge обращаться к папке «Загрузки».
- В окне «Доступна новая версия» и в других диалогах после обновления могла появляться белая стандартная иконка вместо иконки Bridge. Теперь иконка берётся из самого приложения, а после обновления Bridge заново регистрируется в macOS, чтобы Dock и Finder тоже показывали правильную иконку.
